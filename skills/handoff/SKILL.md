# 引き継ぎ資料を書く

1 つのプロジェクトを、複数のセッションで順に引き継いで進めるための資料を書く。書く材料は Claude の記憶ではなく会話記録にする。長いセッションで前半を忘れていても、コンテキストが溢れたセッションを閉じた後の新しいセッションからでも、同じ質で書ける。

## 書くもの

| ファイル | 中身 | 書き方 |
|---|---|---|
| `CLAUDE.md` の「目的」節 | 目的・完了条件・範囲外・発端 | **ユーザーの言葉で書く**。Claude が要約や推測で埋めない |
| `HANDOFF.md` | 現在地・次の一手・ユーザーに聞きたいこと・未完了 | 毎回上書きする。1 画面（40 行程度）に収める |
| `FACTS.md` | 確認できた事実 | 追記する。各項に出所（ファイル・URL・コマンド・誰の発言か）を付ける |
| `DECISIONS.md` | ユーザーが決めたこと | 追記する。**ユーザーの発言を引用できるものだけ** |

ファイルが無ければ下の雛形で作る。ほかのファイル（計画表・未確定リスト・ログなど）は作らない。

## 手順

1. **範囲を決める**：`HANDOFF.md` の「最終更新」より後の会話を対象にする。無ければ全部。引数 `since` があればそれを使う。今の時刻を `bash ~/.claude/skills/handoff/scripts/transcript.sh now` で控えておく。以下 `transcript.sh` は常にこの形（`bash` + フルパス）で呼ぶ。インストール時に実行権限が付かないため
2. **会話記録を読む**：記録の読み込みはサブエージェントに任せ、メインのコンテキストを使わない。サブエージェントには次を渡す
   - `bash ~/.claude/skills/handoff/scripts/transcript.sh show --since <TS>` で会話を読む（決定の引用には `--user-only`）
   - 今の `HANDOFF.md` / `FACTS.md` / `DECISIONS.md` / `CLAUDE.md` の目的節
   - 下の「書き込みのルール」
   - 返してほしいもの：各ファイルへの追記・差し替えの案と、決定ごとの引用元（時刻とセッション ID）
3. **書く**：返ってきた案を確かめてから書き込む。引用が会話記録の文面と一致しない決定は書かない
4. **報告する**：次の 3 つを並べる。ユーザーが違うと言ったものはその場で消す
   - 追加した決定（引用付き）
   - 追加した事実（出所付き）
   - 聞きたいこと（目的が空欄ならここで聞き、答えをそのまま書く）

会話記録が見つからない、または足りないとき：
- 別のディレクトリで作業した可能性がある。`transcript.sh find <プロジェクトのディレクトリ名など>` で探し、見つかったセッションをユーザーに見せて、対象にするかを確かめる。対象にするなら `transcript.sh --dir <ディレクトリ> show --session <ID>` で読む
- それでも無ければ（別の PC で作業した等）、その旨を伝え、今のコンテキストにある分だけで書くかをユーザーに選んでもらう

## 書き込みのルール

- **決定**：ユーザーが決めたと言える発言を、文面を変えずに引用する
  - Claude の提案に「はい」「いいです」と答えた場合は、何に同意したかが会話から特定できるときだけ書く。提案の文と同意の発言の両方を引用する
  - 迷っている・考えている段階の発言（「〜かも」「迷いますね」）は決定にしない
  - 引用できないものは書かず、報告の「聞きたいこと」に回す
- **事実**：出所のあるものだけ。Claude の推測・解釈は書かない。推測は推測と書いて HANDOFF の現在地に置く
- **聞きたいこと**：3 件まで。目的の達成を止めているものだけにする。Claude の提案を並べる場所にしない
- **対象にする話題**：`CLAUDE.md` の目的に関係する会話だけ。同じセッションで別の話をしていたら、その部分は書かず、報告で「対象外にした話題」として 1 行で示す
- 会話記録にあるパスワード・トークン・個人情報は書き写さない

## 雛形

`CLAUDE.md`（無ければ作る。あれば「目的」節だけ足す）

```markdown
## 目的
- 目的：
- 完了条件：
- 範囲外：
- 発端：（依頼元・リンク）

新しいセッションは `HANDOFF.md` から読む。過去の経緯は `FACTS.md` と `DECISIONS.md` を正とし、同じ調査を繰り返さない。
```

`HANDOFF.md`

```markdown
# HANDOFF
- 最終更新：<transcript.sh now の値>（これより後の会話が次回の対象）

## 現在地
## 次の一手
## ユーザーに聞きたいこと
## 未完了
```

`FACTS.md`

```markdown
# FACTS
- <事実> [出所 / 確認日]
```

`DECISIONS.md`

```markdown
# DECISIONS
<!-- ユーザーの発言を引用できるものだけ書く -->

## D-001：<決めたこと>
- 日付：
- 発言：「<ユーザーの発言をそのまま>」（<時刻> / <セッション ID>）
- 補足：（背景・影響。必要なときだけ）
```
